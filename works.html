ワンタップでSOSを送信し、Firebaseを利用して位置情報や履歴をリアルタイム管理できる、実用性を重視した防犯支援システムです。

【使用技術】 HTML / CSS / JavaScript / Firebase

【開発状況】 基本システムは実装済み。今後さらに機能を段階的に追加予定です。

【制作人数】 個人制作

AIアシスタント (VoiceLoid Desktop Client)

Google Gemini APIを利用したAIチャットシステムです。会話機能、音声機能、長期記憶機能に加え、フロントエンド側にLive2Dアニメーションを完全連動。Pythonのマルチスレッドサーバー技術を駆使し、独立したデスクトップアプリケーション（.exe）として動作するレベルまで自力で構築しました。

【使用技術】 HTML / CSS / JavaScript / Python / pywebview / PyInstaller / Gemini API

【開発状況】 デスクトップアプリ化完了。Live2D描画およびコンソールエラーゼロの完全稼働テストに成功。

【制作人数】 個人制作

Life Work Planner（ライフワークプランナー）

日々の目標や予定、習慣、家計簿を直感的に一元管理できるライフプランニングシステムです。洗練されたダッシュボードやカレンダー機能を備え、日常の生産性を最大化します。こちらもパッケージ化を行い、専用デスクトップアプリとして起動可能です。

【使用技術】 HTML / CSS / JavaScript / Python / PyInstaller

【開発状況】 パッケージ化（.exe化）完了。現在デスクトップ上での実稼働テスト中です。

【制作人数】 個人制作
